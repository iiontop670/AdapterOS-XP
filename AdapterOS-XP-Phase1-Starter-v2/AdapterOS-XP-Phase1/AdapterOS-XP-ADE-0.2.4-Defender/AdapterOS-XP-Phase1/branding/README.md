# AdapterOS branding assets

ADE 0.2 uses an original Luna-inspired desktop landscape drawn in QML and original generated WAV effects under `ade/sounds/`.

Future original assets can be added here:

- `adapteros-logo.svg` — original AdapterOS mark
- `login-background.png` — original login background
- `icons/` — original application icons
- `wallpapers/` — original AdapterOS wallpapers

Do not redistribute Microsoft Windows XP logos, proprietary icons, sounds, or wallpaper. The goal is a nostalgic visual language with an original AdapterOS identity.
