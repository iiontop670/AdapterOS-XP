# AdapterOS branding assets

Create original assets here:

- `adapteros-logo.svg` — original AdapterOS mark
- `wallpaper-luna-inspired.png` — original landscape, not a copy of Microsoft's Bliss image
- `login-background.png`
- `icons/` — original application icons
- `sounds/` — original system sounds

Do not redistribute Microsoft Windows XP logos, proprietary icons, sounds, or wallpaper. The goal is a nostalgic visual language with original AdapterOS identity.
